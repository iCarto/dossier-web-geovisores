# iCarto - Soluciones de Visualización Cartográfica Web

Este proyecto es una landing page profesional para soluciones de visualización cartográfica web desarrolladas por iCarto.

## Tecnologías utilizadas
- HTML5 / Tailwind CSS para el diseño y maquetación.
- Ikaros Sans como tipografía corporativa.
- Diseño Responsive para visualización en móviles, tablets y escritorio.

## Estructura del Proyecto
- index.html: Página principal.
- assets/: Imágenes, logos y recursos gráficos.
